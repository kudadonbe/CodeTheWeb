Custom Font Setup

Learn how to add and use custom fonts in your web projects

What is @font-face?

The @font-face CSS rule allows you to use custom fonts in your website without requiring users to have them installed on their computers. You provide the font files, and the browser downloads and uses them automatically.

How to Set Up Custom Fonts

  1. Create a fonts folder:
    Create a folder named fonts/ in your project.
  2. Add your font files:
    Place your font files (.ttf, .otf, .woff, .woff2) in the fonts folder.
  3. Create fontsetup.css:
    Create a CSS file to declare your fonts using @font-face rules.
  4. Link the CSS file:
    Add the link to your HTML file: <link rel="stylesheet" href="fonts/fontsetup.css">
  5. Use the font:
    Apply the font in your CSS: font-family: 'Your Font Name';

Basic @font-face Example

fonts/fontsetup.css
  1. /* In your fonts/fontsetup.css file */
  2. @font-face {
  3. font-family: 'My Custom Font';
  4. src: url('MyFont-Regular.ttf') format('truetype');
  5. font-weight: 400;
  6. font-style: normal;
  7. }
index.html
  1. <!-- Link the font CSS in your HTML -->
  2. <link rel="stylesheet" href="fonts/fontsetup.css">
style.css
  1. /* Use the font in your CSS */
  2. h1 {
  3. font-family: 'My Custom Font', sans-serif;
  4. }

Font Weights & Styles

Use the same font-family name with different font-weight values to create a complete font family:

fonts/fontsetup.css
  1. /* Regular */
  2. @font-face {
  3. font-family: 'My Font Family';
  4. src: url('MyFont-Regular.ttf') format('truetype');
  5. font-weight: 400;
  6. }
  8. /* Bold */
  9. @font-face {
  10. font-family: 'My Font Family';
  11. src: url('MyFont-Bold.ttf') format('truetype');
  12. font-weight: 700;
  13. }
  15. /* Light */
  16. @font-face {
  17. font-family: 'My Font Family';
  18. src: url('MyFont-Light.ttf') format('truetype');
  19. font-weight: 300;
  20. }

Font File Formats

.ttf

TrueType Font

format('truetype')

.otf

OpenType Font

format('opentype')

.woff

Web Open Font Format

format('woff')

.woff2

WOFF Version 2

format('woff2')
Tip: WOFF and WOFF2 formats are optimized for web use and have smaller file sizes. Use them when available for better performance!

Best Practices

  1. Use meaningful font names: Choose descriptive font-family names like 'Roboto Web' instead of generic names.
  2. Provide fallback fonts: Always include system fonts as fallbacks:
    font-family: 'My Custom Font', Arial, sans-serif;
  3. Optimize file sizes: Use WOFF2 format when possible for smaller file sizes.
  4. Check font licenses: Make sure you have the right to use the font on your website.
  5. Test across browsers: Test your custom fonts in different browsers to ensure compatibility.

Loading Sample Text from JSON

The preview text above is loaded at page load from assets/data.json using fetch():

Important: fetch() requires a local server — use VS Code Live Server or python3 -m http.server. Opening the file directly in a browser (file://) will not load the JSON.
assets/data.json
  1. {
  2. "pangram": "ބ... (full Dhivehi pangram)",
  3. "eng": "The quick brown fox jumps over the lazy dog"
  4. }
index.html — <script>
  1. fetch('assets/data.json')
  2. .then(res => res.json())
  3. .then(data => {
  4. document.querySelectorAll('[data-font-sample]').forEach(el => {
  5. el.textContent = data.pangram;
  6. });
  7. });
style.css
  1. /* Using Dhivehi fonts in your CSS */
  3. /* Basic usage */
  4. .dhivehi-text {
  5. font-family: 'Dhivehi Web', sans-serif;
  6. direction: rtl;
  7. text-align: right;
  8. }
  10. /* With font weights */
  11. .dhivehi-heading {
  12. font-family: 'MV Utheemu', sans-serif;
  13. font-weight: 700;
  14. direction: rtl;
  15. }
index.html
  1. <!-- HTML Example -->
  2. <p class="dhivehi-text">
  3. ތާނައިން ލިޔުނީމާ ފެންނަގޮތް
  4. </p>
  6. <h1 class="dhivehi-heading">

Tip: For Dhivehi/Arabic text, always use direction: rtl; and text-align: right; in your CSS for proper text rendering.
