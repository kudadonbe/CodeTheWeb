## 🎨 Common Challenges & Solutions

### **Challenge:** "My styles aren't applying"

**Solutions:**
- Check CSS selector specificity
- Use browser DevTools to inspect
- Verify class/ID names match
- Check for typos
- Clear cache and hard refresh

---

## 🐛 Common Challenges & Solutions

### **Challenge:** "JavaScript not working"

**Solutions:**
- Open Console for error messages
- Check script placement (end of body?)
- Verify element IDs match
- Use `console.log()` to debug
- Check for syntax errors (missing brackets, semicolons)

---

## 🔧 Common Challenges & Solutions

### **Challenge:** "Layout breaks on mobile"

**Solutions:**
- Use responsive units (%, rem, vw/vh)
- Test at different screen sizes
- Use Flexbox/Grid for flexibility
- Add media queries
- Use `max-width` instead of fixed `width`

## 📤 GitHub Pages Setup

```bash
# 1. Initialize git
git init

# 2. Add files
git add .

# 3. Commit
git commit -m "Initial commit - Certificate Generator"

# 4. Connect to GitHub
git remote add origin https://github.com/yourusername/certificate-gen.git

# 5. Push
git push -u origin main
```

Then enable Pages in repository settings!
