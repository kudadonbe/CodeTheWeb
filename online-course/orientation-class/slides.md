## 🌐 A Brief History of the Web

### **The Journey:**

- **1991** – Tim Berners-Lee creates the Web
- **1995** – JavaScript is born
- **2000s** – Web 2.0 (social media, interactive sites)
- **2010s** – Mobile-first, responsive design
- **2020s** – AI, WebAssembly, modern web apps

## 🧱 The Power of Fundamentals

### **HTML, CSS, JavaScript = Foundation of the Web**

- 🏗️ **HTML** – Structure (the skeleton)
- 🎨 **CSS** – Style (the design)
- ⚡ **JavaScript** – Behavior (the brain)

> **Every website uses these three technologies!**
