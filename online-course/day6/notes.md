# Day 6: Building the Certificate Generator Project - Notes

Welcome to Day 6! Today, we will be building a Certificate Generator project. This project will allow you to apply all the HTML, CSS, and JavaScript knowledge you've gained over the past few days.

## Project Overview

The Certificate Generator is a web application that allows you to:
*   Add and manage certificate recipients.
*   Generate certificates dynamically based on recipient data.
*   Print the generated certificates.

## Project Structure

You will find the project files in the `project` subdirectory within this `day6` folder. The main files are:
*   `index.html`: The main page for managing recipients.
*   `print.html`: The page for printing certificates.
*   `recipients.html`: A page to add and manage recipients (likely accessed from `index.html`).
*   `css/styles.css`: For styling the application.
*   `js/`: Contains JavaScript files for dynamic behavior.
*   `data/`: Contains sample data or where data will be stored.
*   `templates/`: Contains HTML templates for certificates.

## Tasks for Today

1.  **Explore the Project:** Spend some time exploring the provided project files. Understand how `index.html`, `print.html`, and `recipients.html` are linked. Look at the CSS and JavaScript files to get a general idea of their purpose.
2.  **Understand Data Flow:** Analyze how recipient data is handled. Where is it stored? How is it displayed? How is it passed to the printing page?
3.  **Dynamic Certificate Generation:** Focus on the `print.html` and the associated JavaScript. Understand how the certificate template is used and how dynamic data (recipient name, course, date) is injected into it.
4.  **Enhancements (Optional):**
    *   Add validation to forms.
    *   Implement local storage to persist recipient data.
    *   Improve the UI/UX of the application.
